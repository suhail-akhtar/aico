# aico for VS Code

Run the [aico](https://github.com/suhail-akhtar/aico) coding agent inside VS Code.

- **Ask about a selection** — highlight code, `Ctrl+Alt+A`, and the file and line numbers go with the question.
- **The full workspace in a panel** — sessions, tool cards with diffs, plans, trajectory.
- **Background work in the status bar** — a run started an hour ago, or a scheduled job that failed overnight, without opening anything.

Requires aico on your `PATH` (`aico.command` if not) and Node 22.5+.
