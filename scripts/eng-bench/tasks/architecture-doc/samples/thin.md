# FieldOps Design

Sample document for the grader self-test: a thin design that should fail most rubric checks.

## Overview

We will build a mobile app and a web app backed by a cloud API and a database. The mobile app will
work offline and sync later. The dispatchers will see updates quickly. Managers will get reports.
We will integrate with the billing system.

## Stack

- React for the web
- A mobile framework
- Node.js
- A SQL database

This stack is modern and scalable and our team will enjoy it.

## Plan

Build everything, test it, and launch it in six months.
